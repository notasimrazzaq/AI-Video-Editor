## Rules
- Kit default (creator's): no sound on slide-ins/exits, no whooshes, ~20 dB under the voice, few sounds.
- Paper Cut style (user asked for crisp paper sounds): sound every landing / tape / tick / stamp / flip; still **no sounds on captions or exits**.
- Sync to the frame the visual event lands, not the tween start.

## How (one list → HTML + fast mix)
1. Write `projects/<name>/sfx.json`: `[[time, "sound-name", volume?], ...]` (volume optional; defaults in `tools/sfx.mjs`).
2. `node tools/sfx.mjs projects/<name>` → writes `<audio>` tags (unique ids, real durations, non-overlapping tracks) into `index.html` between `<!-- sfx:start -->` / `<!-- sfx:end -->`, so every future render includes them.
3. **Already rendered? Don't re-render** (renders are slow):
   `node tools/sfx.mjs projects/<name> --mix renders/with-cards.mp4 renders/with-sfx.mp4` mixes the sounds onto the existing audio with FFmpeg and copies the video stream (~10 s for a 3-min reel). Limiter prevents clipping.
4. `npx hyperframes lint` (expect 0 errors). Check levels: `ffmpeg -ss <t> -t 1 -i out.mp4 -af volumedetect -f null NUL`.
5. Copy the result to `exports/`. Adjust by editing `sfx.json` and re-running step 3 (seconds).

Never touch the `<video>` audio. VS Code's built-in player can't play AAC; preview finished videos in VLC / the default player.
